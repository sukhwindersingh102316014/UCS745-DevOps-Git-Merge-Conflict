# SmartCalc - Cloud & DevOps Lab Demo

A modular Python command-line calculator demonstrating Git version control workflows, branching, and conflict resolution.

## Features (v2.0 - Unified Release)
- **Core Arithmetic Operations**:
  - Addition (`add`)
  - Subtraction (`subtract`)
  - Multiplication (`multiply`)
  - Division (`divide`) with zero-division handling

## Advanced Modules (Unified Post-Merge Resolution)
- **Scientific Operations Module (from `feature/scientific-ops`)**:
  - Exponentiation / Power (`power`) using `a ** b`
  - Square Root calculation (`sqrt`) using Python `math.sqrt()` with negative input validation
- **Financial Operations Module (from `feature/financial-ops`)**:
  - Percentage calculation (`percentage`) representing rate over base
  - Modulo remainder calculation (`modulo`) with zero divisor check
