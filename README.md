# SmartCalc - Cloud & DevOps Lab Demo

A modular Python command-line calculator demonstrating Git version control workflows, branching, and conflict resolution.

## Features (v1.0)
- Core Arithmetic Operations:
  - Addition (`add`)
  - Subtraction (`subtract`)
  - Multiplication (`multiply`)
  - Division (`divide`) with zero-division handling

## Advanced Modules
- Standard operations available. Additional mathematical modules under active development in separate feature branches.
